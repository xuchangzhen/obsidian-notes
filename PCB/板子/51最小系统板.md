# 2. 电源电路

![[Pasted image 20260927101830.png]]

电源电路通过SW1开关来控制外部供电是否进入到开发板当中
我们发现我们虽然都说VCC是供电，3.3V或者5V，但是实际画板过程中，我们往开发板供电的网络标签都是用PWR而不是VCC，这样就可以避免只要插上电开发板就通电

再往下走，是一个电容，然后接到地，这里起到的是滤波的作用，若某一时刻外部供电出现短暂的跳变，电容就可以释放一些电或是吸收一些电，
所以这个电容也叫做 **储能电容**

再往右就是一个通电指示灯了，加了一个限流电阻，避免电流过大烧坏LED

## 2. 去耦电容
![[Pasted image 20260928102900.png|457]]

就是这个0.1uf的小电容，通常用的是瓷片电容
那么他的作用是什么呢？因为他的容量比较小，对于处理供电毛刺，电路电流瞬时变化起到关键作用，还能消除旁路的高频噪声，所以在信号高频变化的引脚附近也会放一个这个东西，通常需要放置在VCC和GND之间，注意，不是放在I2C，SPI引脚旁边

# 4. 晶振电路
![[Pasted image 20260927161636.png]]

晶振电路就长这个样子，但是这个电容是有说法的

[[晶振]](Crystal) 内部存在负载电容，电路周围存在杂散电容，这些都会影响我们外面这两个电容的选择
我们先来看一下公式

$$
C\_L_{负载电容} = {\frac{C1 \times C2}{C1 + C2}} + C_{Stray}
$$

一般我们使用的C1和C2都是一样的，公式转变一下，我们来求一下我们需要放置的电容


$$
C1 = C2 = 2 \times (C\_L - C_{Stray})
$$
通常$C_{Stray}$取2-5pf
至于$C\_L$就要去看具体晶振的参数了
