# 1.  简单介绍

电容(Capacitor)
具有通交流，阻直流的作用
直流：
1. 刚通电时，电路相当于短路，电容快速充电
2. 充满电后，电路相当于断路，电容不再充电
3. 电路出现供电不足时，电容会快速放电，充当一个非常短暂的电源



电容所能保存的电荷量：
$$
Q = CV
$$
$$
I = C\frac{dV}{dt}
$$
我们加一个电路图来理解
![[Pasted image 20260928014746.png|210]]
根据这两个公式，就可以知道电容是怎么滤波的了，公式里面的 $I$ 指的是流过电容的电流，
我们先规定电流方向，我们规定流入电容为正方向，根据基尔霍夫电流定律
$$
I_{电源} = I_{负载} + I_{电容}
$$
然后我们就可以知道当C不变之时，V变大，Q(电容存储电荷量)也会随之变大
根据$I = C\frac{dV}{dt}$，当电源电压电流增大的时候，$I_{电源}\uparrow$,  那么此时 $I_{电容}\uparrow$, 就可以让$I_{负载}$ 趋于一个稳定的样子
			 当电源电压电流减小的时候，$I_{电源}\downarrow$, 那么此时电容就要放电了，那么这个基尔霍夫电流定律就要发生变化，电容放电，方向自下而上，那么这个公式就会变成$I_{电源} = I_{负载} + I_{电容}$, 但是$I_{电容} < 0$, 也说明了让负载趋于稳定，此时电容就会放电，维持负载的电压稳定


还有一个公式放大系数的公式，就是我们认为 A > 0.707就算通过，就是没有截止的意思
$$
A = \frac{V_{in}}{V_{out}}
$$

# 2.  电容滤波

## 1. 高通滤波

![[Pasted image 20260928094826.png|312]]

这个滤波是怎么实现的呢？先不讲公式，这个也可以直接理解，因为电容会阻碍两端电压变化，但是当频率很高的时候，他也要充电，那么他的阻碍作用就会小很多，那么高频信号就可以通过，下面来看一下公式

这是电容所能通过频率的公式，也就是截止频率公式
$$
f_{截止频率} = \frac{1}{2\pi RC}
$$
这个 C 指的是电容的容量，R指的是电路的容抗，  电阻阻抗 R
那电容的容抗应该如何计算呢？
$$
X = \frac{1}{2\pi fc}
$$
也就是说电容的容抗受自身容量和输入频率影响
根据这两个公式也可以很好的理解为什么可以阻碍高频信号了，
$\because$ f $\uparrow$   
$\therefore$ X $\downarrow$   $\Rightarrow$ 电容两端的电压就会小，根据分压公式 $$
U_{负载} = U\frac{R}{R + X}
$$
那么负载两端电压就会变小
那么根据高通滤波也可以得出低通滤波的图了，原理都是一样的

## 2. 低通滤波
![[Pasted image 20260928100531.png|305]]

先简单理解就是波形变化频率小了，所以电容轻轻松松就能阻碍电压的变化，也可以根据上面的公式推导出来


电容放电？

这是何物
\[ V(t)=V_0e^{-t/RC} \]

按键消抖
```
按键电容滤波，本质上就是用 RC 低通滤波把机械按键的“抖动”变成一个比较平滑的电压变化。

机械按键并不是一按下就立刻变成完美的：

```
1 → 0
```

实际触点在接触瞬间可能会反复弹跳：

```
1 0 1 0 1 0 0 0
```

这个过程通常持续几毫秒到十几毫秒。MCU 如果采样得很快，就可能把一次按键误判成多次。

最常见的硬件消抖电路是这样：

```
        VCC
         │
         R
         │
         ├────── MCU GPIO
         │
         C
         │
        GND
         │
      ┌──┴──┐
      │ 按键 │
      └──┬──┘
         │
        GND
```

更严格地画，按键和电容都接到这个节点：

```
        VCC
         │
         R
         │
         ●──── GPIO
        / \
       C   按键
       │    │
      GND  GND
```

未按下时，电阻 R 把 GPIO 拉高：

```
GPIO ≈ VCC
```

同时电容也被充到接近 VCC。

按下按键时，节点被拉向 GND。理想情况下应该瞬间变成 0V，但因为电容两端电压不能瞬间突变，所以它会逐渐放电：

\[ V(t)=V_0e^{-t/RC} \]

于是 GPIO 看到的不再是乱跳的方波，而是一个逐渐下降的电压。

比如没有电容时：

```
按下：

3.3V ─────┐ ┌─┐ ┌─┐
          └─┘ └─┘ └──── 0V
           ↑触点抖动
```

加 RC 后，大致会变成：

```
3.3V ──────╲
            ╲
             ╲____ 0V
```

短时间的抖动来不及把电容充放电很多，所以会被“吃掉”。

松开按键也是一样。

松开瞬间机械触点也会抖：

```
0 1 0 1 0 1 1 1
```

但电容会通过上拉电阻 R 慢慢充电：

\[ V(t)=V_{CC}(1-e^{-t/RC}) \]

GPIO 看到的是：

```
0V ____/
        /
       /
──────/──── 3.3V
```

所以这个电路的核心就是：

> 电容不允许节点电压快速变化，从而过滤掉按键触点产生的短时间快速变化。

这里最重要的参数是：

\[ \tau=RC \]

这个叫时间常数。

例如：

```
R = 10kΩ
C = 100nF
```

那么：

\[ \tau=10\,000\times100\times10^{-9} \]\[ \tau=1ms \]

1 ms 只是“开始明显变化”的尺度，不代表 1 ms 后已经完全充放完。

一般大约：

```
1τ  → 63%
2τ  → 86%
3τ  → 95%
5τ  → 99%
```

所以 10kΩ + 100nF 的完整变化尺度大约是几毫秒。

如果想让滤波更强，例如：

```
R = 10kΩ
C = 1µF
```

那么：

\[ \tau=10ms \]

就能比较明显地抑制按键的几毫秒抖动。

但是电容不能无限加大。假如你用了：

```
10kΩ + 100µF
```

那：

\[ RC=1s \]

你按下按键后，GPIO 可能过很久才识别到，按键手感就会变得很“迟钝”。

你可以把它和你之前学过的 RC 低通直接联系起来。

按键抖动属于“快速变化、高频成分”，而真正的按下/松开属于“慢变化、低频成分”。

RC 低通就是：

```
慢变化 → 通过
快变化 → 抑制
```

所以：

> 按键电容消抖，其实就是 RC 低通滤波的一个实际应用。

不过 PCB 上还有一个细节你以后很容易碰到。如果电容直接并在按键两端：

```
VCC
 │
 R
 │
 ●── GPIO
 │
 C
 │
GND

●── 按键 ── GND
```

当电容已经充到 3.3V，然后你突然按下按键时，电容会瞬间通过按键放电。

理论瞬间电流：

\[ I=C\frac{dV}{dt} \]

由于变化非常快，瞬时电流可能比较大。

小电容如 100nF、1µF 通常问题不大，但如果电容很大，就不应该简单粗暴地直接并在按键上，可能需要加限流电阻。

对于你现在做 51 / STM32 这种板子，常见方案可以先记成：

```
VCC
 │
10kΩ
 │
 ●──── GPIO
 │
100nF
 │
GND
 │
按键
 │
GND
```

然后软件再做一次 10~20 ms 左右的消抖。

实际工程里通常不会只依赖电容，常见做法是：

> 硬件 RC 滤掉尖锐毛刺 + 软件消抖确认状态。

这样最稳。
```
