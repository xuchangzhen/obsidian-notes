
每个三极管都有三个引脚：
- B（Base，基极）：控制端。
- C（Collector，集电极）：主电流通路的一端。
- E（Emitter，发射极）：主电流通路的另一端。

![[Pasted image 20261103182950.png]]

| 特征           | NPN                  | PNP                  |
| ------------ | -------------------- | -------------------- |
| 导通条件         | B 电压高于 E             | B 电压低于 E             |
| 硅管典型导通压差     | $V_{BE}\approx+0.7V$ | $V_{BE}\approx-0.7V$ |
| 传统电流方向       | C → E                | E → C                |
| 常见开关位置       | 低边（GND 侧）            | 高边（电源侧）              |
| STM32 常见控制方式 | GPIO 输出高电平导通         | 需要适当的电平驱动            |
|              |                      |                      |
#### NPN三极管
可以近似理解为放大基极电流，然后放大的电流在CE回路当中
电路中集电极C通常接一个电源，然后接用电器，发射极E介入接入GND 



其实功能差不多，MOS管更强，可能会更贵，所以还是会用三极管
