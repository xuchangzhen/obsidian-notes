# Quartz upstream

This directory contains the Quartz 5 program files imported from
[jackyzha0/quartz](https://github.com/jackyzha0/quartz), branch `v5`, commit
`74b3fc9efd0caafea3dbcd846ddf1f06855b6d2a`.

The upstream MIT license is retained in [LICENSE.txt](LICENSE.txt). Local site
configuration and the content preparation script are maintained separately so
that future Quartz upgrades do not overwrite the Obsidian vault.
