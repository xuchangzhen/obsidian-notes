# 通信相关概念 

## 1.  按总线分

|      | diff              | advantage                 | defect                    |
| ---- | ----------------- | ------------------------- | ------------------------- |
| 串行通信 | 按字节发送数据，一次只发送一个字节 | 1. 消耗总线数量少<br>2. 数据间不存在干扰 | 1. 速度不如并行                 |
| 并行通信 | 按字节发送数据，一次发送多个字节的 | 1. 速度快                    | 1. 消耗总线数量多<br>2. 总线之间存在干扰 |

# 2. 按通信类型分
### 1. 单工通行
只允许单向传输，反向传输不成立

### 2. 双工通信
#### 1. 半双工
可以进行双向通信，但不允许同时发送和接收，一次只能选择一个方向
#### 2. 全双工
可以进行双向通信，允许同时发送和接收，可以同时选择两个方向
