# 1. 特点
串行，异步，全双工


# 2. 概述
1. 字节流传输，每次传输单字节
2. 传输包括 起始位 数据位 校验位 停止位
3. 串口通信规定空闲时总线保持高电平

传输帧

| 起始位 | 高电平->低电平                                   |
| --- | ------------------------------------------ |
| 数据位 | 高电平代表1<br>低电平代表0<br>数据位通常为5-8位             |
| 校验位 | 可有可无，只能校验，无法知道错误的数据<br>奇偶校验当中校验1的个数，0表示奇数个 |
| 停止位 | 低电平->高电平                                   |
|     |                                            |

通信双方波特率应该相同

传输的数据分为文本模式和hex模式，二者发送的数据东西都是相通的，只是形式不同
hex模式发送的是原始ascii码，文本模式是ascii码转换为我们正常人看的东西的形式

数据包：在我们发送的一串数据帧前后加上帧头桢尾，帧头桢尾是我们自定义的，中间夹着数据，数据还是以帧形式传输，也就是依旧是单字节传输，单字节里面还是保留着start和stop的
使用数据包还是有很多好处的
1. 区分消息边界：知道数据的起始和截止位置
2. 错误后重新同步：帧丢失后还能找到下一个数据的帧头
3. 区分命令类型：根据帧头桢尾可以判断出数据类型
4. 易于拓展：添加新命令后只需检查帧头桢尾
5. 支持不同长度：数据封装在帧头桢尾中，根据帧头桢尾确定命令长度
