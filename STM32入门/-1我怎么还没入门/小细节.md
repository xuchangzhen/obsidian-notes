#### 1. 枚举变量实际存储的是整数
使用枚举变量的时候必须避免取地址操作，若对一个枚举变量进行取地址得到的并不是地址，而是一个整数
例如
```c
typedef enum{
	COMMANDPARSE_NONE,
	//COMMANDPARSE_SELECT_SERVO,
	COMMANDPARSE_ADDJUST_PWM,
	COMMANDPARSE_SAVE,
	COMMANDPARSE_TIME_MINUTE,
	COMMANDPARSE_TIME_HOUR,
	COMMANDPARSE_TIME_YEAR
	
} ParseCommand_t;

ParseCommand_t CommandMode		 = COMMANDPARSE_TIME_HOUR
```

进行取地址
```c
&CommandMode
```
得到的不是==COMMANDPARSE_TIME_HOUR==，也不是CommandMode的地址
而是数字3，因为COMMANDPARSE_TIME_HOUR位于枚举类型的第三位
